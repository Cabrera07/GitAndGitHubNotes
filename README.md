# 📚 Git and GitHub Notes

A different kind of Git reference: simple, story-driven explanations built on **analogies and real examples**, instead of dry command lists. If you've ever read a Git tutorial and understood every command but still felt lost about *why* — this is for that gap.

Each topic is explained the same way: a relatable analogy first (LEGO castles, sealed envelopes, sticky notes, shipping labels...), then the real commands, worked examples, and a troubleshooting section for when things go sideways.

## 🛠️ How to Use This Repository

1. Start with **Introduction** if you're new to Git and GitHub altogether.
2. Move to **Configurations and Setup** once you're ready to set up SSH, `git config`, and licensing for your own repositories.
3. Use **Core Git Operations** as your day-to-day reference — staging, committing, undoing mistakes, and untangling states like a detached HEAD.
